# Анализ алгоритмов поиска ассоциативных правил

## Описание проекта

Лабораторная работа посвящена сравнению трёх алгоритмов поиска ассоциативных правил:
- **Apriori**
- **ECLAT** 
- **FP-Growth**

Анализ проводится на данных о покупках из файла `Market.csv`.

## Структура реализации

### 1. Подготовка данных
- Загрузка транзакционных данных без заголовков
- Преобразование в список транзакций
- Создание one-hot кодирования с помощью `TransactionEncoder`
- Удаление пустых значений (NaN)

### 2. Реализация алгоритмов

#### Apriori
- Поиск частых наборов с минимальной поддержкой 0.004
- Генерация ассоциативных правил с минимальной уверенностью 0.004
- Вывод топ-10 правил по уровню поддержки

#### ECLAT
- Использование специализированной библиотеки `pyECLAT`
- Анализ пар товаров (комбинации из 2 элементов)
- Форматирование результатов в DataFrame

#### FP-Growth
- Альтернативный алгоритм для поиска частых наборов
- Аналогичные параметры для корректного сравнения

### 3. Сравнение производительности
- Измерение времени выполнения на различных размерах данных (500, 1000, 2000, 4000, 7000 транзакций)
- Использование модуля `timeit` для точного измерения
- Сравнительный анализ трёх алгоритмов

## Ключевые особенности

- Единые параметры для всех алгоритмов (min_support = 0.004)
- Анализ только парных комбинаций товаров
- Сортировка результатов по поддержке для выявления наиболее значимых правил
- Фокус на сравнении производительности алгоритмов

## Результаты

Код позволяет:
1. Получить ассоциативные правила из данных о покупках
2. Сравнить эффективность трёх алгоритмов
3. Проанализировать зависимость времени выполнения от объема данных
4. Выявить наиболее популярные сочетания товаров

# Анализ алгоритмов коллаборативной фильтрации

## Описание проекта

Проект посвящен реализации и анализу различных подходов к коллаборативной фильтрации для построения рекомендательных систем. Включает использование библиотеки Surprise и собственную реализацию алгоритма на основе косинусного сходства.

## Структура реализации

### 1. Подготовка данных
- Загрузка данных о пользователях, фильмах и рейтингах
- Преобразование данных в разреженную матрицу формата CSR
- Создание объектов Dataset для работы с библиотекой Surprise

### 2. Использование библиотеки Surprise
- Реализация алгоритма KNNBasic с различными метриками схожести:
  - Pearson correlation
  - Cosine similarity
  - Mean Squared Difference (MSD)
  - Pearson baseline
- Оценка качества алгоритмов с помощью метрик MAE и RMSE
- Реализация матричной факторизации с помощью алгоритма SVD

### 3. Собственная реализация коллаборативной фильтрации
- Расчет попарных сходств между пользователями с использованием косинусной меры
- Реализация предсказания рейтингов на основе k ближайших соседей (k=3)
- Заполнение пропущенных значений в матрице пользователь-фильм

## Ключевые особенности

- Сравнение различных метрик схожести для KNN-подхода
- Анализ влияния размера тестовой выборки на качество предсказаний
- Визуализация матрицы пользователь-фильм до и после заполнения пропусков
- Реализация двух подходов: готовой библиотеки и собственного алгоритма

## Результаты

Проект демонстрирует:
1. Работу различных алгоритмов коллаборативной фильтрации
2. Сравнение их эффективности через метрики MAE и RMSE
3. Возможность реализации собственного алгоритма рекомендаций
4. Визуализацию результатов предсказаний

## Технические детали

- Использованные библиотеки: pandas, numpy, scikit-learn, scipy, surprise
- Метрики качества: MAE, RMSE
- Алгоритмы: KNNBasic, SVD, пользовательская реализация на основе косинусной меры
- Формат данных: разреженные матрицы (CSR), DataFrame

# Анализ алгоритмов матричной факторизации для рекомендательных систем

## Описание проекта

Проект посвящен сравнению различных алгоритмов матричной факторизации для построения рекомендательных систем на основе данных о рейтингах фильмов. Исследуются три алгоритма: SVD, FunkSVD и SVD++.

## Структура реализации

### 1. Загрузка и подготовка данных
- Загрузка данных из CSV-файла с рейтингами (userId, movieId, rating)
- Использование библиотеки Surprise для работы с рекомендательными системами
- Создание объекта Dataset с указанием шкалы рейтингов (1-5)

### 2. Реализация алгоритмов

#### SVD (Singular Value Decomposition)
- Классическая матричная факторизация без смещений
- Оценка с помощью перекрестной проверки (5 фолдов)
- Измерение метрик RMSE и MAE

#### FunkSVD (SVD with biases)
- Матричная факторизация со смещениями пользователей и предметов
- Реализация через параметр biased=True в SVD
- Аналогичная оценка качества

#### SVD++
- Усовершенствованный алгоритм, учитывающий неявные взаимодействия
- Более сложная модель с лучшей точностью, но большим временем обучения

### 3. Сравнительный анализ
- Измерение времени выполнения для каждого алгоритма
- Сравнение метрик качества (RMSE, MAE)
- Визуализация результатов с помощью matplotlib
- Анализ стабильности алгоритмов по фолдам перекрестной проверки

## Ключевые особенности

- Использование библиотеки Surprise для быстрого прототипирования
- Детальный анализ времени выполнения и точности алгоритмов
- Визуализация метрик на каждом фолде перекрестной проверки
- Пример предсказания рейтинга для конкретного пользователя и фильма

## Результаты

Проект позволяет:
1. Сравнить три алгоритма матричной факторизации по точности и скорости
2. Выявить компромисс между сложностью модели и временем обучения
3. Визуализировать стабильность алгоритмов на разных подвыборках данных
4. Сделать обоснованный выбор алгоритма для конкретной задачи

## Технические детали

- Используемые библиотеки: pandas, numpy, matplotlib, seaborn, scikit-surprise
- Метрики оценки: RMSE (Root Mean Square Error), MAE (Mean Absolute Error)
- Стратегия валидации: 5-фолдовая перекрестная проверка
- Визуализация: линейные графики сравнения моделей и анализа по фолдам

# Гибридная рекомендательная система для книг

- Выявление 500 наиболее влиятельных пользователей для целевого пользователя
- Формирование списка книг, оцененных похожими пользователями

### 3. Контентный анализ
- Применение TF-IDF для векторизации текстовых обзоров

- Сравнительный анализ производительности подходов

## Результаты

Система позволяет:
1. Находить похожих пользователей на основе оценок книг
2. Рекомендовать книги с учетом текстового содержания обзоров

## Основные этапы анализа

### 1. Загрузка и подготовка данных
- Загрузка графа из файла `facebook_combined.txt`
- Использование 1/6 части данных для уменьшения вычислительной сложности
- Создание графа с 2060 узлами и 14705 ребрами

### 2. Визуализация графа
- Построение исходного графа с помощью spring layout
- Отображение структуры связей без выделения сообществ

### 3. Применение алгоритмов выявления сообществ

#### Алгоритм Лувена
- Обнаружено: 14 сообществ
- Визуализация с цветовым кодированием сообществ

#### Label Propagation
- Обнаружено: 33 сообщества
- Визуализация с разделением на сообщества

#### Алгоритм Гирвана-Ньюмана
- Обнаружено: 2 крупных сообщества
- Визуализация разделения графа

## Используемые технологии
- Python
- NetworkX для работы с графами
- Matplotlib для визуализации
- Алгоритмы выявления сообществ

## Результаты
Сравнение трех алгоритмов показало разное количество и размеры выявленных сообществ, что демонстрирует различные подходы к анализу структуры социальных сетей.
